# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Send a report to `dev@timelogicapi.com` with:

- the affected SDK and version;
- a concise description and reproduction steps;
- the impact you observed; and
- any suggested remediation.

Do not include live API keys, signing keys, or other private credentials in a report. Redact them before sending.

We will acknowledge reports as soon as practical and coordinate a fix and disclosure timeline with the reporter.

## Supported versions

The latest release on the default branch receives security fixes. Older releases may be unsupported; upgrade to the latest compatible version when possible.
